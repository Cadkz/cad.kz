# Продолжение с другого компьютера

Приватный репозиторий создан: https://github.com/Cadkz/cad.kz. Владелец — Cadkz. Вход во встроенном браузере выполнен. Первый push выполнен и содержимое проверено на GitHub: исходники, документация, четыре макета и lockfile находятся в ветке main.

На домашнем ПК:
1. На домашнем ПК войти в тот же GitHub-аккаунт либо аккаунт, имеющий доступ к приватному репозиторию компании.
2. Выполнить `git clone https://github.com/Cadkz/cad.kz.git`, открыть папку проекта.
3. Установить Node 22.18+ и pnpm; выполнить `pnpm install --frozen-lockfile`, если lockfile уже опубликован.
4. Создать локальный `.env` по `.env.example`. Секреты передаются отдельно через принятый в компании защищённый канал. Git не переносит `.env`.
5. Подключить отдельную dev PostgreSQL. Контент БД и медиа не синхронизируются обычным Git: нужен согласованный дамп/экспорт и архив медиа.
6. Прочитать README, docs/PLAN.md, docs/MOCKUPS.md и docs/VERIFICATION.md. Это источник состояния проекта для продолжения в новом чате.

Изменения переносить через commit/push и pull. Не редактировать одни и те же файлы одновременно на двух ПК без синхронизации. Изменения, которые ещё не прошли commit и push, остаются только на текущем ПК.
