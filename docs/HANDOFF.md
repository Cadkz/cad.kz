# Состояние проекта для нового чата

Обновлять в конце каждого этапа. Читать вместе с `AGENTS.md`. Подробности решений — `docs/DECISIONS.md`.

## Сделано (на 08.10.2026)
- Витрина: главная с каталогом и фильтром, товар, новости, статьи, акции, материал, корзина.
- Оформление заказа `/checkout`: серверный пересчёт цены, подтверждение новой суммы, согласие, идемпотентность, лимиты, неизменяемый снимок заказа, очередь CRM с тестовым адаптером Битрикс24 (без сети). В демо честное сообщение «Заявка сохранена. В демоверсии она не передаётся менеджерам.»
- Админка: заказы только для чтения (видит администратор), состав снимка. Менеджеры в CMS не работают: они в Битрикс24.
- Лид в Битрикс24 самодостаточный: контакты, БИН, товары с комплектацией и ценами, комментарий, диалог (когда появится).
- Демо-хостинг подготовлен: миграции, Vercel Blob (`MEDIA_STORAGE=blob`), noindex, автонастройка при сборке на Vercel (`DEMO_AUTO_SETUP=yes`). Инструкция для владельца — `docs/STAGING.md`.

## Демо запущено (08.10.2026)
Сайт работает на Vercel: https://cad-kz.vercel.app (репозиторий открыт, база Neon, хранилище Blob Public). Владелец проверил: каталог, оформление заявки, вход в /admin и заявка в разделе «Заказы». Автонастройка включена переменной `DEMO_AUTO_SETUP=yes`; каждый пуш в main сам обновляет сайт. Загрузка картинок через CMS в Blob ещё не проверена.

## Как запускать локально
`pnpm install`, `.env` по `.env.example`, PostgreSQL, `pnpm dev`. Проверка перед коммитом: `pnpm format`, `pnpm check`, `pnpm build`. Если локальная PostgreSQL остановилась: `pg_ctlcluster 16 main start`.
