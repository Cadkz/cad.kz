## Как запускать локально
`pnpm install`, `.env` по `.env.example`, PostgreSQL, `pnpm dev`. Проверка перед коммитом: `pnpm format`, `pnpm check`, `pnpm build`. Если локальная PostgreSQL остановилась: `pg_ctlcluster 16 main start`.
