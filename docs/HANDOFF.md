## Страница «Импорт из Битрикса» в админке (08.10.2026)
Адрес: https://cad-kz.vercel.app/admin/import-bitrix (только администратор; плашка на главной админки и пункт в меню). Шаги: 1) выбрать четыре файла — они читаются в браузере, на сервер не загружаются и нигде не хранятся; 2) отчёт проверки (то же, что `pnpm import:bitrix`) и кнопка «Скачать полный отчёт»; 3) «Записать в базу» с галочкой «Скрыть демотовары» (включена по умолчанию), полоса хода, при сбое — «Продолжить с места остановки»; 4) «Скачать картинки» со старого cad.kz частями, повторный запуск докачивает остальное.

Как устроено: браузер шлёт план частями в `/api/admin/bitrix-import` (шаги start → products → offers → finish → images, `src/lib/bitrixImportRun.ts`), каждый запрос пишет до 20 с и возвращает, сколько успел. Сервер проверяет каждую часть (`src/domain/bitrixImportInput.mjs`), пускает только администратора и запросы со своей страницы. Ход и итог — в журнале «Запуски импорта». Проверено локально в боевой сборке на искусственной выгрузке (320 товаров, 572 предложения, один файл в Windows-1251, 258 картинок с тестового сервера): запись ~8 с, повтор ничего не меняет, картинки скачались, галереи заполнены. 
Запуск на демо (08.10.2026, владелец, настоящие выгрузки): товаров 651, вариантов с ценой 922, производителей 16, повтор — всё «без изменений». Картинки: скачано 598, галерей заполнено 517 из 553 товаров с картинками, не скачалось 37 (список на странице, причины не разбирались). Первый запуск в журнале остался «не закончен»: он остановился на старой проверке счётчиков, данные при этом записаны.

## Картинки и направления (08.10.2026, вечер)
- Причина 37 не скачавшихся картинок найдена: у GEO5 на старом сайте картинки в GIF, а «Медиа» GIF не принимала (31 товар GEO5 без галереи). GIF разрешён (`src/domain/mediaTypes.mjs` — один список форматов для «Медиа» и импорта), причины сбоя пишутся словами, список можно скачать таблицей. Ещё 5 товаров MagiCAD для Revit/Электроснабжение без галереи, причина не ясна (картинка на старой странице есть и открывается) — после повторного «Докачать картинки» смотреть причину в списке.
- Привязка к направлениям: ни у одного из 731 товара на демо нет разделов. Черновик правил — `src/domain/directionRules.mjs` (производитель + слова в названии → разделы), 53 группы, все товары покрыты. Владелец проверяет группы на странице https://claude.ai/artifact/UM8DJwHdsbVL3cCpopeNSr; выбор сохраняется в её базе (коллекция `groups`, документ на группу: `sections`, `ok`, `comment`), читать через ArtifactData. Предложены 4 новых раздела (`NEW_SECTIONS`): широкоформатные сканеры, расходные материалы, рабочие станции, внедрение и консалтинг.

## Как запускать локально
`pnpm install`, `.env` по `.env.example`, PostgreSQL, `pnpm dev`. Проверка перед коммитом: `pnpm format`, `pnpm check`, `pnpm build`. Если локальная PostgreSQL остановилась: `pg_ctlcluster 16 main start`.
