# Каталог: аудит кода и исправления, 23.10.2026

Проверка по коду и скриншоту владельца, без посещения сайта и Playwright. Область: заявка на товар без готовых комплектаций, карточки разделов и производителей, фильтры, скрытие снятых моделей. Это не полный визуальный аудит сайта.

| Проблема | Причина | Исправление |
| --- | --- | --- |
| «Запросить цену» заблокирована у plotWAVE T75 | PickerAction требовал выбранную строку даже при отсутствии шагов подбора. На телефоне PickerBar предлагал перейти к несуществующему выбору | Общее правило для обеих кнопок: товар без комплектаций можно запросить сразу. В заявку передаётся сам товар, без выдуманного предложения и цены. Для семейства и существующего подбора выбор по-прежнему нужен |
| Итог предлагает выбрать то, чего нет | Пустой подбор трактовался как незавершённый | «По запросу», объяснение действия, сохранён выбор количества |
| Картридж на плитке широкоформатных плоттеров | Первая фотография выбиралась среди всех дочерних товаров, включая расходники | Для родительской плитки подходят только товары из plotters; если фото устройства нет, остаётся иконка |
| Разнородные и несортированные характеристики | Исследование перенесено напрямую в интерфейс | Рулоны объединены по максимальной вместимости с опциями: 2, 4, 6. Исходные характеристики не изменены. Ширины, разрешение и точности отсортированы численно, размеры объектов от XS до XXL, дубль «x/×» объединён |
| Фильтр перегружен | Общие для всех товаров одиночные признаки ничего не уточняют | Такие группы скрыты; выбранные значения остаются, чтобы их можно было снять |
| Выбор теряется из виду на телефоне | Условия видны только внутри панели | Метки выбранных условий над результатами, снятие по одной, очистка условий без выхода из раздела |
| Пустое место у MagiCAD | Нет статического логотипа; резервный путь производителя не заполняет изображение | Читаемая подпись производителя в плитках и карточках ПО. Это текстовая замена, не официальный логотип. Настоящий файл из админки сохраняет приоритет |
| Снятые товары засоряют каталог | Статус исследования показывал только пометку | По новому решению владельца discontinued исключён из общего набора каталога и рекомендаций; он не участвует в плитках и счётчиках фильтров. Прямые страницы сохраняются с пометкой и заменой. Черновики скрыты, отсутствие цены не считается снятием |

## Проверка

Добавлены регрессионные тесты правил заявки и приёма её серверной валидацией, нормализации рулонов и старых URL, числового порядка, выбора фото устройства и исключения пяти снятых моделей. Рабочая CRM не вызывается, настоящие заявки не отправляются. Форматирование, типы, дизайн-токены и полный набор тестов проверяются через pnpm format и pnpm check.

После сборки проверить отправку тестовой заявки согласованным способом, мобильную нижнюю кнопку, плитку плоттеров, фильтры 2/4/6 и возврат по истории. Для настоящего логотипа MagiCAD нужен проверенный файл в поле «Логотип» производителя. Внешние картинки не скачивались, в медиахранилище ничего не загружалось.
