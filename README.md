# Новый CAD.kz

Отдельный прототип. Действующий сайт и Athena AI не затрагиваются.

## Запуск
1. Node.js 22+ и pnpm. Выполнить `pnpm install` (после появления lockfile использовать `pnpm install --frozen-lockfile`).
2. Создать отдельную PostgreSQL БД. Скопировать `.env.example` в `.env`, задать `DATABASE_URL`, случайный длинный `PAYLOAD_SECRET`, `APP_MODE=demo`. Остальные секреты оставить пустыми.
3. `pnpm dev`, открыть http://localhost:3000. CMS: http://localhost:3000/admin.
4. Для пустой БД задать в локальном `.env` BOOTSTRAP_ADMIN_EMAIL и BOOTSTRAP_ADMIN_PASSWORD (16+ символов), выполнить `node --env-file=.env --experimental-strip-types scripts/bootstrap-admin.mjs`, затем удалить эти два значения из окружения. Публичное создание пользователей закрыто. Bootstrap требует Node 22.18+ и ещё не проверен с БД.
5. `pnpm test` — проверка денежного расчёта; `pnpm typecheck` — типы; `pnpm build` — сборка.

Для production сначала создать/проверить миграции (`pnpm payload migrate:create`, затем `pnpm payload migrate`), настроить постоянный каталог media и резервные копии. Автоматическое изменение схемы в production выключено. Текущая версия не готова для публичных продаж.

## Реализованная основа
- Конфигурация Payload/PostgreSQL, русская локализация, коллекции контента, история курсов и закрытые служебные коллекции.
- Адаптивная предварительная витрина с каскадными фильтрами; один конфигуратор для быстрого просмотра и страницы товара.
- `/api/quote` принимает ID демонстрационного предложения и количество. Цена определяется на сервере; деморежим включается явно.
- Расчёт с точной рациональной арифметикой, выделением НДС и правилом HALF_UP.
