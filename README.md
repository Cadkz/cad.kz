# Новый CAD.kz

Отдельный прототип. Действующий сайт и Athena AI не затрагиваются.

## Запуск
1. Node.js 22.18+ и pnpm 11.19.0. Выполнить `pnpm install --frozen-lockfile`.
2. Создать отдельную PostgreSQL БД. Скопировать `.env.example` в `.env`, задать `DATABASE_URL`, случайный длинный `PAYLOAD_SECRET`, `APP_MODE=demo`. Остальные секреты оставить пустыми.
3. `pnpm dev`, открыть http://localhost:3000. CMS: http://localhost:3000/admin.
4. Для пустой БД задать в окружении BOOTSTRAP_ADMIN_EMAIL и BOOTSTRAP_ADMIN_PASSWORD (16+ символов) и выполнить `pnpm payload run scripts/bootstrap-admin.mjs`, затем удалить эти два значения. Публичное создание пользователей закрыто. Проверено с PostgreSQL 16 (08.10.2026).
5. Демонстрационное наполнение (разделы, 12 товаров с комплектациями, новости, акции, курсы USD/EUR, контакты и тексты главной): `pnpm seed:demo` при `APP_MODE=demo`. Повторный запуск обновляет записи по ключу импорта `demo:…`, а не дублирует их.
6. `pnpm check` — всё сразу: Biome (линтер и форматирование), правила дизайн-системы, типы, тесты. `pnpm format` — автоисправление форматирования. `pnpm build` — сборка.

Для production сначала создать/проверить миграции (`pnpm payload migrate:create`, затем `pnpm payload migrate`), настроить постоянный каталог media и резервные копии. Автоматическое изменение схемы в production выключено. Текущая версия не готова для публичных продаж.

## Реализованная основа
- Конфигурация Payload/PostgreSQL, русская локализация, коллекции контента, история курсов и закрытые служебные коллекции.
- Адаптивная предварительная витрина с каскадными фильтрами; один конфигуратор для быстрого просмотра и страницы товара.
- `/api/quote` и `/api/cart` принимают ID опубликованного предложения из CMS и количество. Цена определяется на сервере по курсу и НДС из админки; деморежим включается явно.
- Расчёт с точной рациональной арифметикой, выделением НДС и правилом HALF_UP.
- Общая корзина `/cart` сохраняет ID комплектаций и количества в браузере. `/api/cart` пересчитывает итог на сервере; разные комплектации товара не объединяются.

## Пока не реализовано / не проверено
Страницы по четырём макетам свёрстаны и сверены (docs/MOCKUPS.md): главная с каскадным фильтром, товар `/products/<адрес>`, новости `/news`, статьи `/articles`, акции `/news?kind=promotion`, материал `/news/<адрес>`, корзина `/cart`. Решения, принятые без согласования, — docs/DECISIONS.md. Шрифты Manrope/Inter подключены локально, дизайн-токены в src/styles/tokens.css. Контент витрины демонстрационный и хранится в CMS: страницы читают его из Payload, цены считает сервер по предложениям, курсам и ставке НДС из админки. Оформление `/checkout` и заказы в админке (роль «Менеджер по продажам», только чтение) с неизменяемым снимком заказа и очередью CRM (в демо без отправки) готово; ИИ, рабочий адаптер CRM, повторяемый импорт и полная страница статьи — следующие этапы. Служебные коллекции пока являются заготовками. CMS проверена с PostgreSQL 16: вход, роли, создание публикаций и курсов. Код сохранён в приватном https://github.com/Cadkz/cad.kz, основная ветка main. Сайт ещё не развёрнут на хостинге: порядок запуска демо на Vercel и Neon — docs/STAGING.md (миграции в `src/migrations`, `pnpm demo:setup`).
